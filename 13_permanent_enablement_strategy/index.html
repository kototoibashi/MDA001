    🚀 13. 無線機能（Wi-Fi / BT / セルラー）の恒久有効化・永続化方針書¶

    本ドキュメントでは、本端末（********）において現在無効化されている Radio 機能（Wi-Fi, Bluetooth, セルラー）を、端末の再起動後も常に自動で有効化・日常利用可能（普通のAndroid端末化）にするための恒久化（永続化）方針・手順 をまとめています。

    📌 1. 恒久有効化の目標と解決課題¶

    🎯 到達目標¶

    端末の電源を投入（再起動）した際、特別なコマンド操作を行うことなく以下の状態が自動維持されること。 1. Wi-Fi: 設定画面や通知トグルから自由にオン/オフ・アクセスポイント接続が可能であること。 2. Bluetooth: ペアリングおよび通信が常時可能であること。 3. セルラー (SIM): SIMカードを挿入した際に電波を掴み、モバイルデータ通信・通話が可能であること。

    🔑 2. 永続化に必要な 3 大改変要件¶

    前回の調査・実測テストにより、起動時に以下の 3 つが阻害要因となっていることが特定されています。

    flowchart TD
    Issue1["① Wi-Fiドライバ未ロード<br>(pronto_wlan.ko)"] --> Fix1["init.rc等で自動 insmod"]
    Issue2["② 起動時 noril プロパティ自動注入<br>(init.class_main.sh)"] --> Fix2["スクリプト修正 (noril -> no)"]
    Issue3["③ 機内モードON固定"] --> Fix3["Settings DB で airplane_mode_on -> 0"]

    🛠️ 3. 恒久化実装アプローチ（3 パターン）¶

    本端末は userdebug ビルド（adb root 可能）であるため、複数の永続化アプローチが可能です。

    アプローチ A: /vendor パーティション直接修正法 (最推奨・最もスマート)¶

    システム構成ファイルを直接修正し、標準のAndroid同様にネイティブ動作させる方法です。

    • 前提条件: adb root および adb remount (または Magisk / TWRP)

    • 作業手順:

    • /vendor パーティションの書き込みマウント: 

      adb root
adb disable-verity
adb reboot
adb root
adb remount

    • 起動時 noril 自動注入スクリプトの修正:

    • 対象ファイル: /vendor/bin/init.class_main.sh (Line 40)
    • 修正前: 
      setprop ro.vendor.radio.noril yes

    • 修正後: 

      setprop ro.vendor.radio.noril no

    • Wi-Fi ドライバの自動ロード設定:

    • 対象ファイル: /vendor/etc/init/hw/init.qcom.rc

    • 追加内容: on boot セクションにドライバインサートを追加 

      on boot
    exec u:r:vendor_modprobe:s0 -- /vendor/bin/modprobe -a -d /vendor/lib/modules pronto_wlan
      (または insmod /vendor/lib/modules/pronto_wlan.ko)

    • build.prop の無効化フラグ修正:

    • 対象ファイル: /vendor/build.prop (Line 110)

    • 修正内容: ro.radio.noril=true ➔ ro.radio.noril=false

    • 機内モードの恒久解除: 

      adb shell settings put global airplane_mode_on 0

    アプローチ B: 起動時自動スクリプト法 (Magisk service.d / Boot script)¶

    /vendor パーティションを直接変更せず、起動完了直後にバックグラウンドスクリプトで自動アタッチする方法です。

    • 仕組み: service.d や /system/etc/init/ 内にスクリプトを配置し、boot時に以下を自動実行させる。 
      #!/system/bin/sh
insmod /vendor/lib/modules/pronto_wlan.ko
settings put global airplane_mode_on 0
am broadcast -a android.intent.action.AIRPLANE_MODE --ez state false
ip link set wlan0 up
svc wifi enable
svc bluetooth enable

    アプローチ C: Magisk モジュールによるシステムレスオーバーレイ¶

    Magisk を導入している場合、システムファイルを変更せずにメモリ上で /vendor/build.prop やスクリプトを置き換えます。

    ⚠️ 4. 実行前の安全策・バックアップ¶

    恒久化（ファイルシステムの書き換え）を行う前に、万が一の起動不能（Bootloop）を防ぐため、以下のバックアップを推奨します。

    1. vendor / boot / system パーティションのバックアップ:
    2. 06_backup_strategy.md の手順に従い、dd または QFIL / EDL にて /vendor パーティションのイメージバックアップを作成する。

    📱 5. 純正「設定 (Settings.apk)」アプリで Radio 項目が消えるメカニズムと復元¶

    🧐 なぜ設定アプリから Wi-Fi / BT / セルラー項目が消えているのか？¶

    ユーザーから最も指摘される「設定アプリを開いても Radio 系の項目が丸ごと消えている」問題の根本原因は以下の通りです。

    1. OSの機能宣言 (pm list features) は正常に生きている¶

    調査の結果、PackageManager レベルの機能宣言は一切削除されておらず、完全に残っています。 * feature:android.hardware.wifi ➔ 正常 * feature:android.hardware.bluetooth ➔ 正常 * feature:android.hardware.telephony ➔ 正常

    2. 原因は ro.radio.noril=true による Settings.apk のフィルタリング¶

    Android の純正 Settings.apk (AOSP / CodeAurora Framework) は、設定画面のメニューツリーを描画する際、以下のコード分岐を実行します。

    // AOSP Settings.apk 内部の判定処理イメージ
boolean isNoRadio = SystemProperties.getBoolean("ro.radio.noril", false);
if (isNoRadio) {
    // 画面レイアウトから無線・通信関連の Preference をすべて動的に削除 (removePreference)
    removePreference(KEY_NETWORK_PROVIDER);
    removePreference(KEY_CONNECTED_DEVICES);
    removePreference(KEY_SIM_CARDS);
}

    このプロパティが true になっているため、Settings.apk が起動時に「この端末は無線機能を持たない」と誤判定し、画面レイアウトから項目を非表示化 (removePreference) しています。

    🎉 設定アプリの画面項目を復元させる方法¶

    1. ro.radio.noril の解除 (根本解決):

    2. 永続化手順（アプローチ A）で /vendor/bin/init.class_main.sh の setprop ro.vendor.radio.noril no に修正すると、ro.radio.noril=false となり、設定アプリを次回開いた際に自動的に Wi-Fi, Bluetooth, モバイルネットワーク のメニュー項目がすべて元通り再表示されます。

    3. 直通インテントでの個別起動 (裏技/テスト用): 項目が消えていても、内部の画面 Activity は存在するため、ADB やショートカットアプリ等から以下のインテントを発行すると設定画面を直接開くことが可能です。

    4. Wi-Fi 設定画面を開く: 
      adb shell am start -a android.settings.WIFI_SETTINGS
    5. Bluetooth 設定画面を開く: 
      adb shell am start -a android.settings.BLUETOOTH_SETTINGS
    6. モバイルネットワーク設定画面を開く: 
      adb shell am start -a android.settings.DATA_ROAMING_SETTINGS
